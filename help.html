Pertanyaan umum.

Jawaban singkat untuk hal yang paling sering ditanyakan.

Apakah Slink gratis?

Ya. Gratis, tanpa iklan, tanpa akun, dan tanpa pembelian di dalam game.

Apa bedanya dengan Slither.io?

Slink adalah proyek penggemar yang ditulis dari nol dengan bahasa C dan SDL3. Gerak, kecepatan, ukuran, dan skornya mengikuti rumus Slither.io, tetapi ini bukan game yang sama dan tidak berafiliasi dengan Slither.io.

Bisakah main online bersama pemain lain?

Ada mode online eksperimental yang terhubung ke server resmi Slither.io dan server komunitas Battledome. Mode ini belum diuji di server aslinya dan bisa berhenti bekerja kapan saja kalau server mengubah protokolnya. Server Slither.io tidak dibuat untuk klien pihak ketiga, jadi memakainya bisa melanggar ketentuan mereka; pakai dengan risikomu sendiri. Versi browser hanya punya mode offline.

Kenapa Windows atau Mac memperingatkan bahwa aplikasinya tidak dikenal?

Karena Slink belum memakai sertifikat tanda tangan berbayar (Windows) dan belum dinotarisasi Apple (Mac). Peringatannya normal untuk aplikasi independen. Langkah membukanya ada di halaman Cara pasang.

Kenapa memasang di iPhone repot?

Apple hanya mengizinkan aplikasi yang ditandatangani. Berkas .ipa Slink belum ditandatangani, jadi harus kamu tandatangani sendiri lewat AltStore atau Sideloadly, dan dengan Apple ID gratis masa berlakunya 7 hari. Bagian iPhone juga belum diuji di perangkat sungguhan.

Data apa yang disimpan?

Nama, kulit ular, skor tertinggi, dan setelanmu hanya tersimpan di perangkatmu. Selengkapnya ada di halaman Privasi.

Bagaimana mengganti video pembuka, link YouTube, atau Discord?

Itu untuk yang membangun sendiri aplikasinya dari kodenya: ubah assets/config.txt untuk tautan, dan lihat bagian "Animasi pembuka" di README untuk videonya, lalu bangun ulang.

Menemukan bug atau punya saran?

Tulis di halaman Issues di GitHub proyek ini. Sebutkan perangkat, versi Slink, dan langkah yang membuatnya terjadi.
