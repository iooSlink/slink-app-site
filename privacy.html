Kebijakan privasi.

Singkatnya: tidak ada pelacakan, tidak ada akun.

Situs ini

Situs ini tidak memakai cookie pelacak, analitik, atau iklan. Pilihan bahasamu disimpan di penyimpanan lokal browser. Untuk menampilkan versi terbaru, halaman ini meminta data rilis ke API GitHub, jadi GitHub dapat mencatat alamat IP-mu sesuai kebijakannya sendiri.

Game

Nama, kulit ular, skor tertinggi, dan setelanmu disimpan di perangkatmu saja. Mode offline tidak mengirim data apa pun. Tidak ada akun dan tidak ada pembelian.

Mode online

Saat memilih server Slither.io atau Battledome, Slink terhubung ke server itu dan mengirim nama, kulit, dan gerakanmu, sama seperti klien Slither.io lain. Kebijakan pemilik server itu yang berlaku di sana; Slink tidak menjalankan atau menyimpan data dari server tersebut.

Versi browser

Skor dan setelanmu disimpan di penyimpanan browser (IndexedDB) pada perangkat ini, dan hilang bila kamu menghapus data situs.
