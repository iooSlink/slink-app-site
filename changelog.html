Catatan versi.

Apa yang berubah di setiap versi Slink.


      
Lihat di GitHub

    

  

      
1.1.0 · Online dan banyak platform

      
  • Mode online eksperimental: server resmi Slither.io dan server komunitas Battledome, dengan pemilih server di beranda. Protokolnya dicocokkan dengan klien web Slither.io dan diuji dengan server tiruan; belum diuji di server aslinya.
  • Slink sekarang juga ada untuk Windows, Mac, Linux, iPhone (eksperimental), dan browser, selain Android.
  • Ikon aplikasi dan jendela, serta nomor versi di beranda.
  • Di browser ponsel, mengetik nama dan chat memakai kotak dialog browser.
  • Halaman unduhan ini.

      
1.0.0 · Rilis pertama

      
  • Mode offline melawan bot dengan gerak, kecepatan, skor, dan papan peringkat yang mengikuti Slither.io.
  • Beranda ala SlitherX: chat, peringkat, main, menu, setelan, serta pengaturan bahasa, YouTube, dan Discord.
  • Tema hitam-putih, video pembuka yang bisa diganti, 19 latar belakang, dan 8 bahasa.
